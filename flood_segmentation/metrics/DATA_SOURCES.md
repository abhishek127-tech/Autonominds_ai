# Data Sources & Attribution

No dataset or sample imagery is bundled with this project.

## Primary Dataset: Sen1Floods11

- **Modality:** Sentinel-1 Synthetic Aperture Radar (SAR), including VV and VH polarization.
- **Purpose:** Potential source for training and evaluating flood-inundation segmentation models; it has not been used to train or evaluate the current stub.
- **Repository:** [cloudtostreet/Sen1Floods11](https://github.com/cloudtostreet/Sen1Floods11)
- **Paper:** Bonafilia et al., “Sen1Floods11: A Georeferenced Dataset to Train and Test Deep Learning Flood Algorithms for Sentinel-1,” IEEE/CVF Winter Conference on Applications of Computer Vision, 2020. [DOI: 10.1109/WACV45572.2020.9093606](https://doi.org/10.1109/WACV45572.2020.9093606)
- **License and access:** Verify the license and terms that apply to the specific dataset files in the official repository before downloading, using, or redistributing them. This project does not bundle the dataset or assert that all of its contents are open access or available for unrestricted research use.
